# Memórias Vivas de Umuarama — Preview HTML/CSS/JS

Protótipo estático com três telas:

- `index.html` — Página inicial
- `colecoes.html` — Página de coleções
- `item.html` — Página de detalhe de item do acervo

## Como testar

Abra o arquivo `index.html` no navegador.

Também é possível rodar um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Observações

- Este preview é apenas HTML/CSS/JS puro.
- As imagens usadas são externas, via Unsplash, apenas para simulação visual.
- A estrutura visual foi pensada para depois ser convertida em Blade no Laravel.
